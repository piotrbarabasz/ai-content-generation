# D073 request: three-step Shorts interface

The 2026-10-19 user-selected request extends the existing D073 backlog boundary
with a focused Original Excerpt UI refactor. The pre-existing Production QA task
and its acceptance status remain intact. This change uses the inspected D071
Shorts application/storage services and the separate D072 Director panel; it does
not claim that pending human acceptance for those tasks is complete.

## Use

1. Open Shorts in a completed Standard project. Check the verified source and
   analysis-provider notice, then select **Find 3 Shorts**. Defaults are Original
   Excerpt, the original verified video, three candidates and a 45-second target.
   The configured provider is preserved. The notice distinguishes local heuristic
   analysis from a potentially paid configured LLM call.
2. Select a candidate card and preview its audio/video. Edit the title, Fit/Fill,
   optional verified captions and source-supported hook. Explicitly confirm
   editorial acceptance, then select **Create Short**. This validates the current
   source/settings, saves or reuses the immutable edit revision, retains the
   acceptance and invokes the existing local renderer. Cancellation retains saved
   edits and decisions. Rendering dispatches no narration, image or LLM generation.
3. Preview the verified rendered Short, inspect its resolution/duration and select
   **Save MP4**. The existing export action revalidates the selected output after
   the file dialog and checksum-verifies the bytes before committing the copy.

## Advanced settings

Collapsed by default: analysis source/count/target, retained candidates/revisions,
verified boundaries, per-shot focal points, actual vertical crop preview, external
SRT and burn-in captions, caption font/color/margins, hook duration/suggestions,
explicit decisions, manual save/render, accepted batch rendering, SRT/metadata/ZIP
exports and source/retained-state refresh. Simple and Advanced controls share the
same edit payload; the external-caption checkbox mirrors the Simple checkbox.
Changes invalidate the crop preview and hide outdated export actions.
If captions for a retained edit become unavailable, **Remove unavailable
captions** explicitly clears those settings without changing saved history.

**Advanced -> AI Director** opens the existing independent workflow. A return
button restores Original Excerpt. Entering or leaving Director does not create
a script, narration or image request; its existing approval gates remain in force.

## Compatibility and recovery

- Application, domain, provider and storage contracts are unchanged by this UI
  work. Existing uncommitted D071 analysis/selection repairs are preserved.
- Candidate cards are a view of the existing retained-candidate selection.
  Per-candidate unsaved drafts, including temporarily invalid values, survive
  candidate switches and refresh within this panel session. They are not durable
  artifacts; use Create Short or Advanced Save before closing/changing projects.
- Saved edits, decisions and verified outputs restore on project reopening.
  Existing edit concurrency, source-currentness and output validation remain the
  authority. Stale candidate history is retained and labeled.
- Analysis failures retain previous candidates and phase-specific errors.
  Editing/navigation does not replace a failure with an unsaved-edits message.
  Empty analysis results cannot produce a success message. Existing asynchronous
  dispatch, duplicate-request guard and cancellation cleanup remain in use.
- The host editor already blocks project changes while Shorts/Director is busy;
  the panel also rejects rebinding until cancellation/cleanup finishes.

## Validation

Offline Qt regressions cover empty/verified states, analysis/phases/failures,
three cards and selection, source playback routing, explicit acceptance,
save/render orchestration and revision reuse, drafts across switches/refresh,
progress/cancellation, export and source replacement during the export dialog,
reopen, Advanced synchronization and Director entry without generation.
Live OpenAI analysis calls are forbidden by the test fixture. Rendering uses a
temporary synthetic source and the existing deterministic renderer fixture.

Layout checks exercise review and rendered-output states at **1360 x 800** and
**1050 x 850**. They assert that all three cards and the active primary action fit
without panel scrolling or horizontal overflow. Offscreen PNGs are generated by
setting `D073_SCREENSHOT_DIR` for the layout tests; local visual evidence is under
`.runtime/d073-ui/` (ignored). The Windows offscreen test explicitly loads Segoe UI
to avoid missing default glyphs. The four readable screenshots were visually
inspected. Synthetic media does not establish real playback quality; native
audio/video and human editorial acceptance remain separate checks.

Final focused validation: **93 passed in 57.84s** across the Shorts panel,

modified files.
